# 📌 Project Overview

SunCart is a modern summer-focused eCommerce platform where users can explore  seasonal essentials such as sunglasses, outfits, skincare products, and beach accessories.

The application emphasizes a clean UI, smooth user experience, and secure authentication flow. Users can browse products, view detailed information.

# 🎯 Purpose

### This project demonstrates the implementation of a full-stack eCommerce system using modern web technologies, focusing on:

* Authentication & protected routes
* Dynamic product rendering
* Clean UI/UX with reusable components
* Real-world user flow (browse → login → view details)

---

## 🧭 Layout & Navigation
